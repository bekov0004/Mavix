# 🚀 Transkit

**Transkit** — это современный инструмент с графическим интерфейсом (GUI) для управления JSON-файлами переводов. Забудьте о ручном редактировании вложенных объектов. Теперь вы можете управлять всеми языками в одной удобной таблице.

---

## ✨ Особенности

* **⚡ Tailwind CSS 4 & Vue 3:** Молниеносный и чистый интерфейс.
* **📦 Глубокая вложенность:** Автоматически преобразует `{ "auth": { "login": "..." } }` в плоский ключ `auth.login` для редактирования и обратно.
* **🌍 Multi-language:** Редактируйте все языковые файлы (`en.json`, `ru.json`, `tj.json`) одновременно в одной строке.
* **🔍 Умный поиск:** Мгновенный поиск по ключам переводов.
* **🚀 Zero Config:** Просто запустите в папке с вашими переводами.

---
