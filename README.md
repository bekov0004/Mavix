# 🚀 Transkit

**Transkit** — это визуальный редактор (GUI) для JSON-файлов локализации. Он позволяет управлять переводами вашего проекта через удобный веб-интерфейс прямо в браузере, поддерживая вложенные структуры, поиск и интеграцию с Excel.

---

## 📦 Установка

Установите пакет глобально или локально в ваш проект:

```bash
# Локально (рекомендуется)
npm install transkit --save-dev

# Или глобально
npm install -g transkit

```

---

## ⚙️ Настройка

Для работы Transkit необходимо создать файл конфигурации **`transkit.config.json`** в корне вашего проекта. Это укажет инструменту, где искать ваши файлы переводов.

```json
{
  "localesPath": "./src/i18n/locales"
}

```

* **localesPath**: Путь к папке, где лежат ваши файлы `{lang}.json`.
* **languages** (опционально): Список поддерживаемых языков.

---

## 🚀 Запуск

После установки и создания конфига, запустите Transkit командой:

```bash
# Если установлен локально
npx transkit

# Если установлен глобально
transkit

```

После запуска откройте в браузере: `http://localhost:3000` (или порт, указанный в консоли).

---

## ✨ Основные функции

* **📝 Редактирование JSON:** Удобная таблица для всех языков сразу.
* **🌳 Поддержка Dot-Notation:** Работайте с ключами вида `user.profile.name`, Transkit сам соберет их в правильное дерево.
* **📊 Excel Import/Export:** Выгружайте переводы для переводчиков и загружайте обратно без потерь.
* **🔍 Глобальный поиск:** Мгновенный поиск по ключам и значениям.
* **🌓 Dark Mode:** Поддержка темной темы.

---

## 🛠 Требования

* **Node.js**: версии 16.x или выше.
* **Формат файлов**: JSON.
